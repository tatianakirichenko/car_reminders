# 🔔 Car Reminder Diary — не дай забыть о важном

> «Напомни вовремя — сэкономь нервы и деньги»

**Car Reminder Diary** — это набор консольных приложений для создания и управления напоминаниями, связанными с автомобилем.  
Программа помогает отслеживать сроки замены масла, ТО, страховки, налога и любых других важных событий.

## 🚀 Особенности
- 📝 Добавление напоминаний: название, дата, пробег (км), описание, приоритет (низкий/средний/высокий).
- 📅 Автоматическое оповещение о приближающихся событиях (за 7, 3, 1 день).
- 🔍 Поиск и фильтрация по названию, дате, приоритету.
- 🗑️ Удаление и редактирование напоминаний.
- 📊 Статистика: количество активных, выполненных, просроченных напоминаний.
- 💾 Автосохранение в JSON-файл (`reminders.json`).
- 🎨 Цветной вывод в терминале и интерактивное меню.
- 📤 Экспорт в CSV (где реализовано).

## 🛠️ Установка и запуск

Для каждого языка — минимальные зависимости (в основном стандартные библиотеки).

| Язык       | Зависимости              | Команда запуска                         |
|------------|--------------------------|-----------------------------------------|
| Python     | стандартная библиотека   | `python car_reminders.py`               |
| Go         | стандартная библиотека   | `go run car_reminders.go`               |
| Ruby       | стандартная библиотека   | `ruby car_reminders.rb`                 |
| Java       | стандартная библиотека   | `javac car_reminders.java && java car_reminders` |
| JavaScript | Node.js, никаких         | `node car_reminders.js`                 |
| C#         | .NET (или mono)          | `dotnet run`                            |
| Rust       | `serde`, `serde_json`    | `cargo run`                             |
| PHP        | стандартная библиотека   | `php car_reminders.php`                 |

> Все программы создают файл `reminders.json` в той же папке.
